# Underworld Revisited 日本語化プレビュー版（2026年10月13日）

『Ultima Underworld: The Stygian Abyss』の再実装プロジェクト
[Underworld Revisited](https://github.com/PQMarine/UnderworldRevisited) を基にした、
非公式の日本語化プレビュー版です。

## ダウンロード・導入

Windows 10/11（64ビット）向けの `UnderworldRevisited-ja-preview-20261013-win64.zip` を展開し、
`UR.exe` を起動してください。ゲームデータの場所を求められたら、
正規のGOG版『Ultima Underworld 1+2』の `game.gog` があるフォルダを選択します。

ZIPには日本語の導入説明書 `README_JA.txt` と、より詳しい `README_JA.md` が入っています。
まず `README_JA.txt` をお読みください。

**原作のゲームデータは同梱していません。** ご自身で正規のゲームデータをご用意ください。

## 日本語化の内容

- 原作の文字列データ7,091件を確認し、6,874件を日本語化しました。
- 合言葉、ルーン、マントラ、リザードマン語、特殊な書式など217件は、ゲームの仕組みや謎解きのため原文を維持しています。
- ゲーム中の会話、道具、書物、状況表示、設定画面、操作案内などの日本語表示に対応しています。
- `You read the 巻物...` のような英語と日本語の混在メッセージ、装備の損傷表示、名前入力欄の配置などを修正しています。
- 日本語翻訳は `Localization/ja.tsv` に収録されています。

## 検証・既知の課題

- UnityによるWindows版ビルドは成功しています。
- 日本語版と英語版の自己診断は成功し、翻訳データの機械検証はエラー0件・警告0件です。
- **プレビュー版です。** 日本語文字の収まり、すべてのゲーム画面での表示、長時間プレイについては十分に実機検証できていません。
- 原作の画像に直接描かれた英語や一部の表示には、改善が必要な場合があります。
