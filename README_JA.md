# Underworld Revisited 日本語化試作版

『Ultima Underworld: The Stygian Abyss』の再実装プロジェクト
[Underworld Revisited](https://github.com/PQMarine/UnderworldRevisited) を日本語化するための試作版です。
公式の日本語版ではありません。

## 現時点でできること

- ゲーム内の翻訳対象の文章を日本語で表示します。
- **6,874件**の日本語訳を収録しています。原作の文字列データに含まれる通常の翻訳対象はすべて対応しました（原文7,091件のうち6,874件を日本語化）。
- リザードマンの架空言語、会話の入力語、合言葉、ルーンやマントラ、開発用の固定書式など**217件**は、ゲームの仕組みや謎解きが成立するよう原文のまま残しています。
- 原作画像に直接描き込まれたセーブ・ロード、音楽・効果音、画質設定、終了確認の英語ボタンも、起動時に英語部分を消して日本語の文字を重ねます。原作画像そのものやセーブデータは変更しません。
- 上部の「ゲーム・移動・画質・表示・操作・音声・色補正」メニューと、ヘルプの7つのタブ、呪文40件の説明、マントラや操作案内も日本語化しています。日本語用フォントはパソコンにインストールされたものを使用します。
- 操作設定のキー・ゲームパッドボタンの名前や、割り当てが重複した時の注意書き、説明書のページ移動表示も日本語化しています。操作ヘルプの117行は原作式・現代式とゲームパッドを含めて自動照合済みです。
- 実際の設定画面を撮影して見つかった「移動」画面と「画質」メニューの重なりを修正しました。上部の項目を切り替えると、前の設定画面は閉じます。幅の狭い「ゲーム」メニューの文章を短くし、画面表示、音声機器の状態、色補正の説明などに残っていた英語も追加で翻訳しました。
- 原作の文字列データ以外の画面文言は対応を進めている途中です。未対応の説明や画像中の文字は英語のまま表示される場合があります。
- 日本語のボタンと設定画面はUnity上の検証に合格しています。修正前の設定画面は実機で撮影して問題を特定しました。今回の修正後については画面切替の機械検証と文字幅の測定まで完了し、設定画面の最終的な実画像確認は引き続き必要です。
- 日本語の表示には、PCにインストールされた Noto Sans JP、游ゴシック、メイリオなどを使用し、原作風の画面でも読みやすいよう**太字のゴシック**で表示します。

## 必要なもの

Windows 10以降の64ビットPCと、**GOG版『Ultima Underworld 1+2』の正規ゲームデータ**が必要です。
この配布物に原作のゲームデータは含まれていません。

## 起動方法

1. 配布用ZIPを展開します。
2. `UR.exe` を起動します。
3. ゲームデータを求められたら、GOG版の `game.gog` があるフォルダを選択します。
4. 日本語訳は `Localization/ja.tsv` から自動的に読み込まれます。

原作風の画面でも、日本語の文字は日本語対応フォントに切り替わります。英語は従来の原作フォントを維持します。日本語の長文は文字幅を見積もって自動改行します。ただし文字の収まりや一部の画面には、まだ改善の余地があります。
操作方法は同梱の `README.txt` と `Docs/CONTROLS.md` を参照してください。

## 翻訳の修正

`Localization/ja.tsv` はUTF-8形式で、1行が「文字列ブロック番号・文字列番号・日本語訳」の3列です。列はタブで区切ります。
`\n` はゲーム中の改行に変換されます。原作の `STRINGS.PAK` は変更しません。

この版は**ゲーム画面全体での日本語表示や文字の収まりについて検証中**です。未翻訳の英語、折り返し、表示幅の問題が残る可能性があります。
